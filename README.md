
# Sales Analysis Dashboard

## Overview
This Sales Analysis Dashboard provides in-depth insights into sales performance using advanced Excel tools. The dashboard helps analyze key metrics like revenue, order trends, product performance, and customer behavior, making data-driven decision-making easier.

## Features
- **Total Orders & Revenue Generated** – Track business performance.
- **Revenue by Occasion** – Compare sales during different events (Anniversary, Diwali, Valentine's Day, etc.).
- **Revenue by Category** – Identify top-selling product categories (Soft Toys, Sweets, Mugs, etc.).
- **Top 10 Cities by Orders** – Understand regional demand distribution.
- **Revenue by Month & Hour** – Analyze seasonal and hourly sales trends.
- **Top 5 Products by Revenue** – Discover best-selling products.
- **Interactive Filters** – Users can filter data by year, order date, and occasion.

## Excel Tools & Techniques Used
- **Power Query** – Data cleaning and transformation
- **Pivot Tables** – Dynamic data summarization
- **Pivot Charts** – Visual representation of key metrics
- **Data Relationships** – Connecting multiple data sources
- **Slicers & Filters** – Enhancing interactivity

## Key Insights
- **Anniversary & Raksha Bandhan** generate the highest revenue.
- **Soft Toys & Sweets** are the most profitable product categories.
- **Kavali & Machilipatnam** are among the top cities for orders.
- **Sales peak during specific hours and months.**

## How to Use
1. Download the project and open it in **Microsoft Excel**.
2. Use **interactive filters & slicers** to analyze different sales aspects.
3. Explore the **Pivot Tables & Charts** for data-driven insights.
